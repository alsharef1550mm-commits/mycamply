# صندوق كلماتي في كامبلي — MyCamply

صفحة مذاكرة مع مدرس Cambly، مع حفظ تقدم مشترك بين الأجهزة على Netlify.

## نقطة البداية

- البداية من **Chapter 1 — Home & Neighborhood** بصفر من 70 كلمة وصفر فصول منجزة.
- جميع الفصول غير منجزة، ويتقدم المستخدم بنفسه أثناء الدراسة.
- بناءً على تعديل الطلب بتاريخ 2026-09-27، يستخدم الحفظ نسخة v2 جديدة لا تستورد الإنجاز المسبق القديم، مع بقاء رابط الصندوق نفسه صالحًا. هذا انتقال لمرة واحدة؛ لا يصفر الإنجاز الجديد عند كل فتح للصفحة.
- الصفحة الرئيسية تختار أول فصل غير مكتمل تلقائيًا. مراجعة الفصل المنجز لا تمسح تقدمه.
- درجات الاختبار تبقى فارغة إلى أن يُجرى اختبار فعلي؛ لم تُختلق درجات للإنجاز السابق.

## النشر على Netlify

1. اربط مستودع GitHub `alsharef1550mm-commits/mycamply` بموقع جديد في Netlify.
2. اترك Base directory فارغًا. الملف `netlify.toml` يحدد أمر البناء ومجلد النشر والوظائف تلقائيًا.
3. انشر الموقع باستخدام الربط بالمستودع. رفع مجلد HTML يدويًا بالسحب والإفلات لا ينشر وظيفة حفظ التقدم.
4. افتح الموقع، وانتظر ظهور **All progress saved across devices**.
5. اضغط **Use on another device** واحفظ الرابط الخاص، وافتح **الرابط نفسه** على الجوال والكمبيوتر. الرابط العام وحده لا يحدد صندوقك على جهاز جديد.

يستخدم الحفظ Netlify Functions و[Netlify Blobs](https://docs.netlify.com/build/data-and-storage/netlify-blobs/) على مستوى الموقع؛ يبقى عند إعادة النشر إلى الموقع نفسه. لا يحتاج قاعدة بيانات خارجية أو مفتاح Netlify في واجهة المستخدم. يُحفظ المفتاح الخاص في fragment الرابط ومتصفحك، ويُستخدم عبر Authorization؛ المخزن يستخدم بصمة SHA-256 للمفتاح. كل من يملك رابطك الخاص يستطيع قراءة التقدم وتعديله.

عند انقطاع الاتصال تحفظ الصفحة التغييرات محليًا وتعيد المزامنة. دمج التقدم يحفظ الكلمات والجمل من الجهازين وأفضل نتيجة اختبار وأحدث تقييم مراجعة. الكتابة المشروطة بـETag تمنع استبدال تقدم أحدث بطلب قديم. يظهر فشل الحفظ بوضوح، ولا يُعرض نجاح المزامنة قبل تأكيد الخادم.

## المحتوى والتدريب

- 10 فصول، 70 مفردة، 144 تمرينًا وسؤالًا أصليًا، ومقدمة المصدر الكاملة في مكتبة الدروس.
- **With my teacher** يعرض جميع تمارين الفصل وأسئلته بترتيب الملف، دون اشتراط فتح الاختبار.
- **Quick Review** يربط الكلمة بتمارينها الأصلية، وسؤال شخصي مخصص، وشرح معناها، وصياغة جملة، وتدريب على مثالها؛ يميّز الأسئلة الإضافية عن المصدر.
- يمكن تخطي أسئلة الاختبار دون الإجابة أو كشف الحل، وتظهر أعداد الأسئلة المتروكة في النتيجة دون نقاط إضافية. يمكن كذلك تخطي كل سؤال في المراجعة وجلسة المدرس وإعادته، أو تخطي الكلمة/تمرين الكتابة كاملًا دون تسجيل إنجاز أو تقييم.
- تقييم المراجعة: Again بعد دقيقة، Remembered يبدأ بيوم، Easy يبدأ بأربعة أيام. تتباعد المراجعات عند النجاح.
- إجابات المحادثة شخصية، وليست أسئلة ذات إجابة واحدة. مفاتيح تمارين المفردات إضافات تعليمية وليست منقولة من مفتاح إجابة داخل الملف.

## التطوير والتحقق

استخدم Node.js 24 وpnpm 11.19.0:

```sh
pnpm install --frozen-lockfile
pnpm run typecheck
pnpm test
pnpm --filter @workspace/kambley-word-box build
node scripts/preview.mjs
```

افتح `http://127.0.0.1:5173`. المعاينة تستعمل محاكي Netlify Blobs ببيانات محلية منفصلة. محاكي الإصدار 11 لا يعيد ETag مع GET، لذا يستخدم الاختبار والمعاينة adapter محليًا يقرأه من list؛ هذا لا يدخل بناء Netlify. اختبارات التعارض محلية ومتتابعة، وليست اختبار تحميل متزامن على خدمة Netlify الفعلية.

تعليمات الحفاظ على القالب وإضافة ملفات لاحقة: [دليل إضافة المحتوى](docs/CONTENT-WORKFLOW.md).
